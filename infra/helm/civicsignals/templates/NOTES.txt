1. SECRETS — the default values contain placeholder strings ("CHANGEME").
   Replace them BEFORE exposing this release to any network:

     helm upgrade {{ .Release.Name }} ./infra/helm/civicsignals \
       --set secrets.databaseUrl="postgresql+asyncpg://user:pass@pgbouncer:6432/civicsignals" \
       --set secrets.secretKey="$(openssl rand -hex 32)"

   Better: use a sealed-secrets or External Secrets Operator integration.

2. INGRESS — TLS is disabled by default. Enable with cert-manager:

     ingress.web.tls.enabled=true
     ingress.api.tls.enabled=true
     ingress.annotations."cert-manager.io/cluster-issuer"="letsencrypt-prod"

3. MIGRATION — an Alembic `upgrade head` Job ran as a pre-install hook.
   Check its logs:

     kubectl logs -l app.kubernetes.io/component=migrate -n {{ .Release.Namespace }}

4. SCHEDULER SINGLETON — the scheduler Deployment uses strategy=Recreate
   and replicas=1. Do NOT manually scale it. Redis-based leader election
   is planned for task D14.
