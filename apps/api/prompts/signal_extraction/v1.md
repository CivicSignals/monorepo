Read the document below and extract every buying signal it contains. A signal is
one of these coarse types:

- `rfp_posted` — a request for proposals/quotations/bids being issued
- `rfi_rfq` — a pre-RFP information-gathering solicitation
- `contract_expiring` — a contract with an end date in the next 6-12 months
- `contract_awarded` — a contract being awarded to a vendor
- `budget_approved` — a budget allocation or approval for a spending category
- `grant_awarded` — a grant received
- `grant_opportunity` — a new grant program open for applications
- `leadership_change` — a personnel change in IT/procurement/executive leadership
- `board_agenda_item` — an upcoming agenda item discussing one of the above
- `strategic_plan_published` — a new multi-year strategic/technology/capital plan
- `open_job` — a posted job in a procurement-relevant role
- `news_mention` — a news article naming an entity in a procurement context

Output ONLY a JSON object of the form:

{{"candidates": [
  {{"signal_type": "rfp_posted",
    "confidence": 0.0-1.0,
    "fields": {{"title": str, "entity_name": str|null, "amount_cents": int|null,
               "due_at": "YYYY-MM-DD"|null, "summary": str}}}}
]}}

`fields` is free-form; include whatever the document supports for the type. Cap
each `confidence` at 0.95 — perfect certainty is suspicious. If the document
contains no signal, output `{{"candidates": []}}`.
