Read the document below and extract every buying signal it contains. A signal is
one of these types. EVERY candidate must include a non-empty `title` and `summary`
in its `fields`; the type-specific required fields are noted in [brackets]:

- `rfp_posted` — a request for proposals/quotations/bids being issued [due_at]
- `rfi_rfq` — a pre-RFP information-gathering solicitation
- `contract_expiring` — a contract ending soon [vendor_name, expires_at]
- `contract_awarded` — a contract being awarded to a vendor [vendor_name]
- `budget_approved` — a budget allocation/approval [amount_cents, category, fiscal_year]
- `grant_awarded` — a grant received
- `grant_opportunity` — a new grant program open for applications
- `leadership_change` — a personnel change in IT/procurement/executive leadership
  [role, person_name]
- `board_agenda_item` — an upcoming agenda item [meeting_date, topic]
- `strategic_plan_published` — a new multi-year strategic/technology/capital plan
- `open_job` — a posted job in a procurement-relevant role [role]
- `news_mention` — a news article naming an entity in a procurement context

Output ONLY a JSON object of the form:

{{"candidates": [
  {{"signal_type": "rfp_posted",
    "confidence": 0.0-1.0,
    "fields": {{"title": str, "summary": str, "entity_name": str|null,
               "amount_cents": int|null, "due_at": "YYYY-MM-DDTHH:MM:SSZ"|null}}}}
]}}

Field rules:
- Dates/datetimes are ISO-8601 (`YYYY-MM-DD` or `YYYY-MM-DDTHH:MM:SSZ`).
- Monetary amounts are integer cents in `amount_cents` (e.g. $400,000 → 40000000).
- Include `entity_name` (the government/education org the signal is about) whenever
  the document names it.
- Cap each `confidence` at 0.95 — perfect certainty is suspicious.
- Only emit a candidate when you can supply that type's required fields; otherwise
  omit it. If the document contains no signal, output `{{"candidates": []}}`.
